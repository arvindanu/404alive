BACKGROUND MUSIC GOES HERE
==========================
Drop .ogg (recommended), .mp3 or .wav files into this folder.
The game scans it at start-up and plays every track it finds as a shuffled playlist
on the "Music" audio bus. No code changes needed.

- Music is automatically muffled by a low-pass filter as the creature gets closer.
- Recommended: OGG Vorbis, stereo, 44.1 kHz, ~96-128 kbps to keep the APK small.
- Re-open the project in the Godot editor once so the new files are imported.
